# Teacher guide

Teachers use their own account and operate only classes assigned to them. Before a class, confirm the class roster and room devices with the administrator. The [first 30 minutes guide](README.md) walks through an initial practice run.

## Your first sign-in

An administrator gives you a username and a **temporary password**. The first time you sign in, imPress asks you to **choose your own password** (8 or more characters with upper and lower case, a number and a special character; the meter shows how strong it is), what it should call you, and a look (light, dark or automatic). You are then offered a short **tour**, which you can skip and take again later from the **?** button. Details: [accounts and first sign-in](../guides/accounts-and-onboarding.md).

You see **only the classrooms you manage**. Your overview is a set of widgets you can add, remove, resize and drag (**Customise**). Press **Ctrl K** (**⌘ K** on a Mac) to search classrooms, students, quizzes and polls, and to change settings such as dark mode or text size without leaving the page. [Personalization and accessibility](../guides/personalization.md) lists everything you can adjust.

If you are signed in on another device, or are idle for 30 minutes during your class (5 minutes otherwise), imPress signs you out.

## Open a class

1. Sign in over the HTTPS address supplied by the operator.
2. Choose **My Classes** and open the class for the current session.
3. Check the title, course/section, room, schedule and roster count. The class page shows quizzes, polls and live device status.

Expected: the correct section is open and its devices are shown. If the class is absent, ask an administrator to check your account, faculty assignment and the class's active status. Do not switch to another staff account.

## Create and run a quiz

1. Choose **+ New Quiz** on the class page.
2. Enter a title. Add one or more questions; each question has 2–4 options, one per line. Put `*` before the correct option. Example:

   ```text
   *A liquid
   A gas
   A solid
   ```

3. Choose **Planned** when you want to create and review the quiz before it reaches students. Choose **Impromptu** only when it should become live immediately.
4. Choose **Manual** for teacher-controlled advance, **Per-Question Timer** for a countdown on each question, or the total-duration option if offered. Check the displayed duration before creating the quiz.
5. Review all questions and correct options, then select **Create Quiz**.
6. For a planned quiz, return to the class and choose **Start**. During a manual quiz, choose **Next** after allowing time for responses; choose **Stop** to end early. A timed quiz advances/ends when its configured timer expires.
7. When the quiz is completed, select **Results** to review responses.

Expected: the quiz status changes from draft to active and then completed; a connected class receives the active question, answer counts update, and results are available afterward. If an option is missing or too long on a module, simplify the text and rerun a practice quiz. Student modules have four physical answer buttons, so never add more than four choices.

If a quiz was accidentally created as impromptu, stop it from the class page and check its status before creating a replacement. Do not assume that refreshing a browser cancels a live quiz.

## Create and run a poll

1. Select **+ New Poll** on the class page.
2. Enter the question and 2–4 options, one per line.
3. Choose **Live** to start immediately or **Planned** to wait until you select **Start** from the class page.
4. Watch the vote count. Select **End** when the response period is over, then **Results** to review the totals.

Expected: a live poll is visible immediately; a planned poll stays in draft until started; a closed poll exposes its results. If the class has no live modules, responses may not arrive. Check device status with the operator before repeating the poll.

## Results and student privacy

Results and student records are classroom data. Use only the information needed for teaching, export only when authorized, and store exports in an approved location. Ask an administrator about account, roster, or device corrections; do not post student data or session links in public support requests.
